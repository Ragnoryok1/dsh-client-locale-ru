# Changelog

Все значимые изменения пакета. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [SemVer](https://semver.org/lang/ru/).

Пакет следует за харнессом: целевая версия — `dsh 0.2.0-rc.2` и новее
(`>=0.1.0-rc.2 <0.3.0` для `@deepseek-ai/dsh-client-locale`).

## [0.1.9] — 2026-10-02

### Добавлено

- **Синхронизация с `dsh 0.2.0-rc.2`**: 37 новых ключей в шести namespace — `chat`
  (единицы длительности и строка «Углублённый анализ»), `conversation` (вопросы,
  ожидающие ответа), `model` (пустой поиск), `pluginManager` (подсказки установки,
  несовместимость версий, порядок обновления), `question` (асинхронные вопросы:
  ожидание, ответы, пропуск) и `workspace` (сессии без названия).
  Покрытие — **2287 из 2287** ключей новой базы.
- **Расширен диапазон совместимости** до `>=0.1.0-rc.2 <0.3.0`: контракт локали
  (`addLanguage` и `register`) в 0.2.0 не изменился, проверено по дереву тега.

### Изменено

- Аудит в CI переведён на тег `dsh-v0.2.0-rc.2`; проверка против 0.1.7-rc.2
  по-прежнему проходит (2264 из 2264), поэтому пакет работает на обеих ветках.

## [0.1.8] — 2026-09-27

### Добавлено

- **Русская экранная типографика** (`src/client/typography.ts`): «ёлочки» вместо прямых
  кавычек, длинное тире между словами, многоточие, неразрывный пробел между числом и
  следующим словом или единицей измерения. Правила осторожные: код, поля ввода,
  редактируемый текст и `[data-typography="off"]` не трогаются, повторный проход ничего не
  меняет. Работает как `ctx.effect`, поэтому выгружается вместе с плагином.
- **Проверки в CI** (`.github/workflows/verify.yml`): сборка, 12 правил типографики
  (`scripts/check-typography.mjs`) и аудит локали (`scripts/audit.mjs`) против
  **закреплённого тега** харнеса. Новые npm-скрипты: `check:typography`, `audit`, `verify`.
- Раздел README **«Область покрытия»** с измерением: из 17 самых скачиваемых плагинов
  экосистемы 11 не поставляют собственных строк, поэтому их русский интерфейс обеспечивают
  словари харнеса; словари сторонних плагинов в область пакета не входят.

### Исправлено

- **Число переводов в документации**: 2598 → **2304**. Прежняя цифра считала повторяющиеся
  имена ключей в разных namespace дважды.

## [0.1.7] — 2026-09-27

### Исправлено

- **Мёртвый namespace `schedule.catalog`.** В 0.1.6 было ошибочно записано, что этот
  namespace упразднён и заменён на `schedule.manager`. На деле в харнесе существуют оба:
  `schedule.catalog` — каталог напоминаний в шапке сессии вместе с частотами и единицами
  времени, `schedule.manager` — менеджер задач автоматизации. Из-за неверного вывода
  около 30 строк перевода (`trigger.*`, `list.*`, `delete.*`, `frequency.*`, `cron.*`,
  `unit.*`, `relative.*`, `mark.aria`, `hover.more`) регистрировались под именем, которое
  никто не читает, и никогда не показывались в интерфейсе.
- **Числительные, неверные на числах 2–4.** Русский требует трёх форм для `n ≥ 2`, а
  компоненты харнесса выбирают форму как `count === 1 ? 'ключ.one' : 'ключ.other'`.
  Переписаны 17 пар ключей (`.one` — естественная форма для `n = 1`, `.other` —
  конструкция, корректная при любом `n ≥ 2`) и 8 строк с `{count}` перед склоняемым
  словом. Пример: «2 субагентов» → «Субагентов: 2», «каждые 2 часов» → «каждые 2 ч»,
  «ещё 3 строк» → «ещё 3 стр.».
- Единицы измерения в частоте повтора: `unit.hour.other` «часов» → «ч» и аналогично
  для минут, секунд и дней; `cron.time.everyMinutes` «минут» → «мин».

### Добавлено

- **Namespace `schedule.manager` (188 ключей)** — менеджер задач автоматизации полностью
  на русском: панель и каталог задач, поиск, фильтр состояний, сведения о задаче и её
  вкладки, журнал запусков с правилами хранения, редактор расписания (дата, время, час,
  минута, секунда, часовой пояс, интервал повтора), правила повтора (разово, каждые
  N минут/часов/секунд, ежедневно, понедельник — пятница, еженедельно, свой cron),
  cron-форма с выбором дат и минуты, удаление с подтверждением, уведомления, карточки.
  55 ключей приходят из общего frequency-словаря, поэтому их текст совпадает с каталогом.
- 7 ключей: `blocked.composer`, `defaultWorkspace.title`, `schedule.active`,
  `settings.transcript.expanded`, `status.scheduled`, `status.overdue`, а также namespace
  `shortcuts.layout` с подписью команды показа левой панели.

### Инструменты

- Аудит **имён** namespace (`audit-namespaces.mjs`): имена извлекаются из всех способов
  объявления (`const NS`/`SETTINGS_NS`/`namespace`, `locale.register`, `locale.bind`,
  `PropsLocale<…>`) и сравниваются множествами. Прежняя проверка покрытия сверяла ключи
  внутри namespace, но не сверяла имена, из-за чего целый namespace мог тихо не работать.

### Состояние

52 namespace, 2304 перевода, ~2700 строк. Проверки: 0 отсутствующих ключей против
`dsh 0.1.7-rc.2`, 0 мёртвых namespace, 45/45 пар ключей с формами числа.
